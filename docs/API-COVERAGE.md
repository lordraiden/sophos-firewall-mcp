### 4.5 Pagination

`page` (1-indexed, default 1), `pageSize` (default 50) and `pageTotal` (default false).

A `pageSize` maximum of 100 is declared only on `getUsers`, `getAdministrators` and `getNetworkUsers`.

- Validate `page >= 1` before sending: the appliance accepts `page=0` with 200 but the contract requires `minimum: 1` (live observation 2026-11-15).
- Validate `1 <= pageSize <= 100` before sending: the appliance returns 400 `invalidPageSizeParam` above 100 in every tested listing, including ones with no declared maximum.
- `pageTotal=true` adds `pages.total` and `pages.items` to the response (live observation 2026-11-15).
- No `limit`, `offset` or cursor exists anywhere in the contract; do not invent one.
- Return one page per MCP call; do not auto-paginate or fetch every page.
- `/authentication/live-users` declares no page parameters; the appliance accepts them but v1 does not expose them (the contract stays authoritative).
